## 1. Export Safety Architecture & Pre-Release Pipeline

All file exports in Sprout (Word `.docx`, PDF, iCalendar `.ics`, ZIP archives) must execute within a strict sandbox container and pass through the **5-Step Export Safety Pipeline**:
1. **Classification Filter:** Hard database query filter excluding unauthorized note classifications.
2. **Metadata Scrubbing:** Strip author name, machine username, organization, and GPS/Exif tags (`scrub_docx_metadata()`).
3. **Automated Redaction:** Masking third-party minors, non-case parent data, and caregiver addresses in High-Conflict mode.
4. **Recipient Watermarking:** Application of tracking headers: `"CONFIDENTIAL • PREPARED FOR [RECIPIENT] • NOT FOR REDISTRIBUTION"`.
5. **Human Review Sign-Off:** Mandatory modal preview where the authorized caregiver checks affirmative confirmation before file generation.
