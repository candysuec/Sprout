## Flow 3: Vermont Mileage Reimbursement Flow (Form FS-334B)

```
[Transport Child to Family Time / Therapy / Court]
               │
               ▼
[Click "Log Note" ➔ Check "Travel / Mileage"]
               │
               ▼
[Enter Trip Miles (e.g. 18.0 mi) + Select Preset Destination]
               │
               ▼
[System applies $0.67 statutory state rate]
               │
               ▼
[At Month End: Click "Reports" ➔ Generate State Form FS-334B (.docx)]
               │
               ▼
[Email to DCF Family Services Resource Coordinator]
```
